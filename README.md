# Snake-Water-Gun-Game
A simple snake, water, gun game developed using Python.
The game allows the player to play against the computer, with the computer making a random choice each round.
The program compares the player's choice with the computer's choice and determines the winner according to the game rules. It also displays the choices and the final result.

Technology used is Python.
Key Concepts are Conditional Statements, loops, functions, user input, random module, and basic programming logic.
